# 基于MQTT协议的企业设备运行监测与远程控制系统 系统设计说明书

## 1. 总体架构

```
┌─────────────────────────────────────────────────────────────┐
│                      浏览器（B/S 前端）                        │
│   Vue3 + Element Plus + ECharts + Pinia + Vue Router + Axios │
└──────────────────────────────┬──────────────────────────────┘
                               │ HTTP/HTTPS (JWT)
┌──────────────────────────────▼──────────────────────────────┐
│                   Spring Boot 后端（Java 21）                 │
│  Controller → Service → Repository(JPA) → MySQL              │
│  Spring Security + JWT（RBAC 权限）                            │
│  MQTT Client(Paho)：订阅 /kettle/pub，发布 /{devId}/sub        │
└───────────────┬──────────────────────────────┬──────────────┘
                │ MQTT                         │ JDBC
     ┌──────────▼──────────┐          ┌────────▼────────┐
     │  MQTT Broker(Moquette)│         │  MySQL 数据库    │
     └──────────▲──────────┘          └─────────────────┘
                │ MQTT 发布/订阅
     ┌──────────┴──────────┐
     │  设备采集器/模拟器     │
     │  (发布 aiValueRpt)    │
     └─────────────────────┘
```

## 2. 功能框图

```
基于MQTT协议的企业设备运行监测与远程控制系统
├── 1. 登录认证与权限
│   ├── 用户登录 / 退出
│   ├── 用户管理（CRUD、启停、重置密码、分配角色）
│   ├── 角色管理（CRUD、分配权限）
│   └── 菜单/权限管理（树形维护）
├── 2. 设备管理
│   ├── 设备台账（CRUD、搜索、分页）
│   └── 点位管理（采集点 AI / 控制点 DO 的 CRUD）
├── 3. 数据采集（MQTT）
│   ├── 订阅 /kettle/pub 接收上报
│   ├── 解析 aiValueRpt JSON 数据帧
│   └── 写入 device_data 表
├── 4. 远程控制（MQTT）
│   ├── 选择设备与控制点、设置目标值
│   ├── 封装 doValueRpt JSON 控制帧
│   ├── 发布到 /{devId}/sub
│   └── 记录控制日志
├── 5. 数据查询与图形分析
│   ├── 最新数据看板
│   ├── 历史数据查询（分页/筛选）
│   └── 趋势折线图（ECharts）
└── 6. 统计报表
    ├── 汇总统计（设备/点位/数据/控制次数）
    ├── 设备类型分布图（饼图）
    └── 点位数值统计（最大/最小/平均）
```

## 3. 业务流程图

### 3.1 数据采集流程

```
采集器 ──(发布 aiValueRpt)──▶ MQTT Broker(/kettle/pub)
                                   │
                                   ▼
                       后端 MQTT 订阅回调（收到消息）
                                   │
                                   ▼
                    校验 devId / msgType / 解析 JSON
                                   │
                                   ▼
                  遍历 data 字段（AI1..AIn），按点位映射
                                   │
                                   ▼
                        批量写入 device_data 表
                                   │
                                   ▼
                   更新设备在线状态、刷新前端实时看板
```

### 3.2 远程控制流程

```
用户在界面选择设备与控制点、填写目标值
                │
                ▼
     后端校验权限（button: control:send）
                │
                ▼
     封装 doValueRpt JSON 控制帧（devId/data/timestamp）
                │
                ▼
     MQTT 发布到 /{devId}/sub
                │
                ▼
     写入 control_record 表（操作人/时间/状态）
                │
                ▼
     设备收到控制帧并执行，回传状态（可扩展）
```

### 3.3 用户登录鉴权流程

```
用户输入账号密码 ──▶ 后端校验 ──▶ 生成 JWT ──▶ 返回 token + 用户信息/权限
        │
        ▼
前端存储 token，后续请求携带 Authorization: Bearer <token>
        │
        ▼
JWT 过滤器解析并校验 token，注入 SecurityContext（含权限标识）
        │
        ▼
接口使用 @PreAuthorize 校验权限；前端按权限渲染菜单/按钮
```

## 4. 模块划分（后端分层）

| 层 | 职责 | 关键类 |
|----|------|--------|
| controller | 接收 HTTP 请求、参数校验 | DeviceController 等 |
| service | 业务逻辑、事务 | DeviceService、ControlService |
| repository | 数据访问 | DeviceRepository 等 |
| entity | 领域对象（JPA 实体） | Device、DeviceData |
| security | 认证鉴权 | JwtAuthenticationFilter、SecurityConfig |
| mqtt | MQTT 连接、订阅、发布、解析 | MqttService、MqttMessageHandler |
| simulator | 模拟设备上报 | DeviceSimulator |
| config | 配置类 | MqttConfig、CorsConfig |

## 5. 技术选型

| 技术 | 选型 | 说明 |
|------|------|------|
| 后端框架 | Spring Boot 3.3.x | Java 21 |
| 数据访问 | Spring Data JPA | 简洁 CRUD |
| 数据库 | MySQL 9 | utf8mb4 |
| 安全 | Spring Security + JWT(jjwt) | RBAC |
| MQTT | Eclipse Paho v3 | 订阅/发布 |
| Broker | Moquette（内嵌，可选外部） | 开发自包含 |
| 前端 | Vue 3 + Vite + Element Plus + ECharts + Pinia | 现代化 SPA |
| 构建 | Maven + npm | |
