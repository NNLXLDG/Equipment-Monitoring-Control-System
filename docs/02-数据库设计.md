# 基于MQTT协议的企业设备运行监测与远程控制系统 数据库设计说明书

## 1. 概念设计（E-R 模型）

系统主要实体及联系：

```
[用户 User] ──< 用户-角色 >── [角色 Role] ──< 角色-权限 >── [权限 Permission]
                                │
[设备 Device] ──< 设备点位 DevicePoint >  (1:N，一台设备有多个采集点/控制点)
     │
     ├──< 采集数据 DeviceData >   (1:N，一台设备产生多条采集记录)
     └──< 控制记录 ControlRecord > (1:N，一台设备产生多条控制记录)

[用户 User] ──< 控制记录 ControlRecord >  (1:N，一个用户可发起多次控制)
```

### 实体及主要属性
- **用户（User）**：用户ID、用户名、密码、姓名、手机、邮箱、状态。
- **角色（Role）**：角色ID、角色名、角色编码、描述、状态。
- **权限（Permission）**：权限ID、父级ID、名称、类型、路径、组件、权限标识、图标、排序。
- **设备（Device）**：设备ID、设备编号、设备名、类型、型号、厂商、位置、状态、安装日期。
- **设备点位（DevicePoint）**：点位ID、设备ID、点位编码、点位名称、类型(采集/控制)、单位、量程、缺省值。
- **采集数据（DeviceData）**：数据ID、设备ID、设备编号、点位编码、数值、采集时间。
- **控制记录（ControlRecord）**：记录ID、设备ID、设备编号、点位编码、目标值、操作人、状态、时间。

## 2. 逻辑设计（表结构）

数据库名：`device_monitor`，字符集 `utf8mb4`。

### 2.1 系统权限相关

**sys_user 用户表**
| 字段 | 类型 | 说明 |
|------|------|------|
| id | BIGINT PK AUTO | 主键 |
| username | VARCHAR(50) UK | 登录名 |
| password | VARCHAR(100) | BCrypt 密码 |
| real_name | VARCHAR(50) | 姓名 |
| phone | VARCHAR(20) | 手机 |
| email | VARCHAR(100) | 邮箱 |
| status | TINYINT | 1启用 0停用 |
| remark | VARCHAR(255) | 备注 |
| create_time | DATETIME | 创建时间 |
| update_time | DATETIME | 更新时间 |

**sys_role 角色表**
| 字段 | 类型 | 说明 |
|------|------|------|
| id | BIGINT PK AUTO | 主键 |
| role_name | VARCHAR(50) | 角色名 |
| role_code | VARCHAR(50) UK | 角色编码 |
| description | VARCHAR(255) | 描述 |
| status | TINYINT | 1启用 0停用 |
| create_time | DATETIME | 创建时间 |
| update_time | DATETIME | 更新时间 |

**sys_permission 权限表（菜单/按钮）**
| 字段 | 类型 | 说明 |
|------|------|------|
| id | BIGINT PK AUTO | 主键 |
| parent_id | BIGINT | 父级ID，0为根 |
| name | VARCHAR(50) | 名称 |
| type | TINYINT | 1目录 2菜单 3按钮 |
| path | VARCHAR(200) | 路由路径 |
| component | VARCHAR(200) | 前端组件 |
| perm | VARCHAR(100) | 权限标识，如 device:add |
| icon | VARCHAR(50) | 图标 |
| sort | INT | 排序 |
| status | TINYINT | 1启用 0停用 |

**sys_user_role 用户角色关联表**
| 字段 | 类型 | 说明 |
|------|------|------|
| id | BIGINT PK AUTO | 主键 |
| user_id | BIGINT | 用户ID |
| role_id | BIGINT | 角色ID |

**sys_role_permission 角色权限关联表**
| 字段 | 类型 | 说明 |
|------|------|------|
| id | BIGINT PK AUTO | 主键 |
| role_id | BIGINT | 角色ID |
| permission_id | BIGINT | 权限ID |

### 2.2 业务相关

**device 设备表**
| 字段 | 类型 | 说明 |
|------|------|------|
| id | BIGINT PK AUTO | 主键 |
| dev_id | VARCHAR(32) UK | 设备唯一标识（MQTT 主题用） |
| device_name | VARCHAR(100) | 设备名称 |
| device_type | VARCHAR(50) | 设备类型 |
| model | VARCHAR(50) | 型号 |
| manufacturer | VARCHAR(100) | 厂商 |
| location | VARCHAR(100) | 安装位置 |
| status | TINYINT | 1在线 0离线 |
| install_date | DATE | 安装日期 |
| description | VARCHAR(255) | 描述 |
| create_time | DATETIME | 创建时间 |
| update_time | DATETIME | 更新时间 |

**device_point 设备点位表（属性/控制参数）**
| 字段 | 类型 | 说明 |
|------|------|------|
| id | BIGINT PK AUTO | 主键 |
| device_id | BIGINT | 所属设备 |
| point_code | VARCHAR(16) | 点位编码（AI1/DO1） |
| point_name | VARCHAR(50) | 点位名称 |
| point_type | TINYINT | 1采集(AI) 2控制(DO) |
| data_type | TINYINT | 1数值 2布尔 |
| unit | VARCHAR(20) | 单位 |
| min_value | DECIMAL(12,3) | 量程下限 |
| max_value | DECIMAL(12,3) | 量程上限 |
| default_value | VARCHAR(32) | 缺省值 |
| description | VARCHAR(255) | 描述 |
| create_time | DATETIME | 创建时间 |

**device_data 采集数据表**
| 字段 | 类型 | 说明 |
|------|------|------|
| id | BIGINT PK AUTO | 主键 |
| device_id | BIGINT | 设备ID |
| dev_id | VARCHAR(32) | 设备编号 |
| point_code | VARCHAR(16) | 点位编码 |
| point_name | VARCHAR(50) | 点位名称 |
| value | VARCHAR(64) | 原始值 |
| num_value | DOUBLE | 数值（用于统计） |
| unit | VARCHAR(20) | 单位 |
| collect_time | DATETIME | 采集时间 |
| create_time | DATETIME | 入库时间 |

索引：`idx_data_dev_time(dev_id, point_code, collect_time)`

**control_record 控制记录表**
| 字段 | 类型 | 说明 |
|------|------|------|
| id | BIGINT PK AUTO | 主键 |
| device_id | BIGINT | 设备ID |
| dev_id | VARCHAR(32) | 设备编号 |
| point_code | VARCHAR(16) | 控制点编码 |
| point_name | VARCHAR(50) | 控制点名称 |
| value | VARCHAR(32) | 目标值 |
| msg_type | VARCHAR(32) | 消息类型 |
| operator_id | BIGINT | 操作人ID |
| operator_name | VARCHAR(50) | 操作人 |
| status | TINYINT | 0已发送 1执行成功 2失败 |
| response | TEXT | 响应内容 |
| create_time | DATETIME | 下发时间 |

- 应用启动时可通过 `spring.sql.init` 自动执行，也可手动执行。
